# frontend-lab

Small, focused demos of modern frontend features I write about on X ([@JonathanSchndr](https://x.com/JonathanSchndr)).

Vue, Nuxt, Vite, Tailwind CSS, TypeScript and the newest web platform APIs, each one a self-contained example you can open, read and copy.

**Live:** https://jonathanschndr.github.io/frontend-lab/

## Demos

Every demo lives in its own folder under `demos/` (named `YYYY-MM-topic`) and is never overwritten.
